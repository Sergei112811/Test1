## Vercel

Пользователь настраивает Preview Deployment для ветки `arena/01a10bd7-test1`.

Если Vercel не видит ветку:

1. Проверить Project → Settings → Git: подключён репозиторий `Sergei112811/Test1`.
2. Проверить доступ GitHub App Vercel к этому репозиторию.
3. В Project → Deployments → Create Deployment указать Git Reference `arena/01a10bd7-test1`.
4. Production Branch оставить `main`.
5. После статуса Ready у Preview выбрать меню `...` → Promote to Production.

Публичный домен и его текущая production-версия пока не подтверждены пользователем. В новой сессии сначала спросить, какой коммит сейчас промоутнут в Vercel.

## Реализованные маршруты

- `/` — лендинг
- `/api/leads` — диагностика через GET и отправка заявки через POST
- `/robots.txt`
- `/sitemap.xml`
- `/favicon.ico`
- `/opengraph-image`

Без Telegram-переменных POST `/api/leads` честно возвращает HTTP 503, а интерфейс предлагает позвонить. Ложного успеха нет.

## Переменные окружения

Секретные значения никогда не сохранять в Git и не принимать текстом в чате.

- `NEXT_PUBLIC_SITE_URL` — публичный адрес сайта; без него индексация запрещена.
- `TELEGRAM_BOT_TOKEN` — серверный токен Telegram-бота.
- `TELEGRAM_CHAT_ID` — серверный ID чата для заявок.

В Vercel у переменных должны быть включены Production и Preview. После изменения переменных необходим новый деплой без старого build cache.

## Подтверждённый продуктовый бриф

### Автомобили

1. LADA Largus фургон, 2018 год — один автомобиль.
   - Ориентировочная грузоподъёмность до 750 кг, требуется подтверждение по документам.
   - Внешние габариты автомобиля: 4,48 × 1,73 × 1,62 м.
2. УАЗ Профи фургон — один автомобиль.
   - Грузоподъёмность до 1,5 тонны.
   - Внешние размеры фургона: 3 × 2 × 1,8 м.

Внутренние размеры грузовых отсеков и год выпуска УАЗ пока неизвестны.

### Условия

- Аренда без водителя.
- Срок от одного дня до одного года.
- Без залога.
- Безлимитный пробег по всей России.
- Выдача в Москве, район Люблино.
- Обычно автомобиль можно получить на следующий день после обращения при наличии свободной машины.
- Категория водительских прав B.
- Основной арендодатель — физическое лицо.
- Новый клиент оплачивает первую неделю заранее; затем возможна оплата в конце недели по согласованию.
- Наличный и безналичный расчёт.
- Продление дистанционно по новому договору или при встрече.
- Автомобиль выдаётся и возвращается с полным баком.
- ОСАГО действует, водитель вносится в полис. КАСКО нет.
- Плановое обслуживание и ремонт не по вине арендатора входят в аренду.
- Топливо, штрафы, парковки, платные дороги и эвакуацию оплачивает арендатор.
- Если арендатор не виноват в ДТП, расходы несёт арендодатель, дни ремонта исключаются из аренды и проводится перерасчёт.
- Если повреждение произошло по вине арендатора, ответственность определяется договором, а дни ремонта не компенсируются.
- Юридические формулировки договора требуют проверки юристом.

### Требования к клиенту

- Гражданство РФ.
- Возраст от 25 лет.
- Стаж от двух лет.
- Паспорт РФ, водительское удостоверение и регистрация в России.
- Управлять может только человек, указанный в договоре и допущенный по ОСАГО.
